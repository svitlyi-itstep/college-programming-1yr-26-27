## Складання програм з розгалуженням

Написати програму на мові C#, яка розв'язує **три задачі з розгалуженням** — по одній з кожного рівня складності (номери варіантів — у таблиці «Розподілення варіантів»). Задачі виконуються в одній програмі послідовно, кожна — під своїм заголовком.

**Вимоги до програми:**

- вхідні дані **вводяться користувачем** з клавіатури, кожне введення — з підказкою (`Console.Write`)
- результат виводиться **зрозумілим повідомленням** українською мовою
- фіксовані значення з умови (ціни, ліміти, пароль тощо) оголошуються **константами** (`const`)
- у задачі **рівня 3** обов'язкова **перевірка введення** через `int.TryParse` / `double.TryParse`: на некоректних даних програма не повинна аварійно завершуватися, а має вивести повідомлення про помилку
- програму потрібно **перевірити на різних вхідних даних** так, щоб спрацювала кожна гілка розгалуження

### Приклад програми

Нижче надано код програми, яка перевіряє швидкість руху автомобіля:

```C#
// ПЕРЕВІРКА ШВИДКОСТІ РУХУ
// до 50 км/год - норма, 51-70 - попередження, понад 70 - штраф

Console.WriteLine("Перевірка швидкості руху");

// Введення та перевірка вхідних даних
Console.Write("Введіть швидкість автомобіля (км/год): ");

if (!int.TryParse(Console.ReadLine(), out int speed) || speed < 0)
{
    Console.WriteLine("Помилка: швидкість має бути цілим невід'ємним числом");
}
else if (speed <= 50)
{
    Console.WriteLine($"Швидкість {speed} км/год у межах норми");
}
else if (speed <= 70)
{
    Console.WriteLine($"Попередження: перевищення на {speed - 50} км/год");
}
else
{
    Console.WriteLine($"Штраф! Перевищення на {speed - 50} км/год");
}
```

Результат роботи для різних вхідних даних — у кожному запуску спрацьовує інша гілка:

```text
Перевірка швидкості руху
Введіть швидкість автомобіля (км/год): 45
Швидкість 45 км/год у межах норми
```

```text
Перевірка швидкості руху
Введіть швидкість автомобіля (км/год): 64
Попередження: перевищення на 14 км/год
```

```text
Перевірка швидкості руху
Введіть швидкість автомобіля (км/год): 92
Штраф! Перевищення на 42 км/год
```

```text
Перевірка швидкості руху
Введіть швидкість автомобіля (км/год): abc
Помилка: швидкість має бути цілим невід'ємним числом
```
